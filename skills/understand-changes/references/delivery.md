# Выдача HTML из чата

Пользователь должен получать готовую точку входа, а не предложение найти файл. В текущем чате файловая ссылка не сработала; пользователь подтвердил открытие обычной локальной HTTP-ссылки 2026-11-03. Поэтому основной путь для локальных сессий — проверенный loopback preview. Генератор возвращает `delivery.preview_argv`, файловую ссылку и browser-opening fallback.

## Основная выдача

В финальном ответе:

1. Коротко назови предмет объяснения.
2. Запусти `delivery.preview_argv` долгоживущим процессом, сохрани его идентификатор, дождись `verified_http:true`. Выведи возвращённый `browser_link` как Markdown-ссылку вне backticks/code fence. Не используй выдуманный порт или URL.
3. Ссылка живёт до остановки процесса или истечения срока (по умолчанию два часа). Сам файл сохраняется постоянно. При просьбе открыть старый разбор после остановки preview запусти новый процесс для того же файла и выдай новую ссылку; не генерируй quiz заново. Если инструмент не сохраняет процессы после окончания хода, явно предупреди об этом и используй browser-opening fallback.
4. Сообщи, что ждёшь «дальше» или вопросов.

При запросе открыть страницу используй `open_argv` как массив аргументов процесса без shell. Если инструмент принимает только shell-команду, используй `open_command` в указанной `command_shell` (`posix` или `powershell`). Не интерполируй путь вручную. `launch_requested:true` означает, что системный browser launcher принял запрос; это не проверка видимого окна или прохождения quiz.

Если preview запрещён sandbox или недоступен, используй штатное разрешение на запуск, если оно доступно в среде. Не меняй bind на внешний адрес. Если запуск остаётся недоступен, сообщи причину и предложи `open_command` как fallback. Файловую ссылку можно добавить как вспомогательную, но не выдавать её за проверенный способ открытия. Точный `open_command` также можно дать как копируемую команду. Открытие уже созданного HTML не запускает повторный рендер и не меняет порядок вариантов.

## Локальный preview

`python3 <skill>/scripts/preview.py PATH.html` обслуживает только один HTML snapshot, только на `127.0.0.1`, на свободном порту и по случайному маршруту. Нет listing каталога или доступа к соседним файлам. Перед выдачей ссылки сервер делает настоящий GET и сравнивает байты с артефактом. `--port` позволяет выбрать порт; `--lifetime-seconds` задаёт срок 1–86400 секунд (default 7200). Ctrl+C или остановка процесса выключает preview. По окончании срока процесс завершается самостоятельно. HTTP-проверка не доказывает визуальную корректность страницы.

## Поверхности и ограничения

Документация проверена 2026-11-03:

| Поверхность | Способ | Подтверждение и предел |
|---|---|---|
| Локальный desktop-интерфейс Codex / ChatGPT | Ссылка на абсолютный путь HTML | [Документация файлового просмотра](https://learn.chatgpt.com/docs/artifacts-viewer) описывает интерактивное HTML preview при доступности этой функции. Наличие функции в конкретной установке проверяется отдельно |
| Claude Code Desktop, локальная сессия | Путь HTML в чате | [Preview your app](https://code.claude.com/docs/en/desktop#preview-your-app) документирует открытие HTML в Browser pane |
| Codex CLI | Файловая ссылка плюс команда открытия в браузере | [Clickable citations](https://learn.chatgpt.com/docs/config-file/config-advanced#clickable-citations) зависят от terminal/editor integration; ссылка может вести в редактор. Встроенный HTML preview в CLI не заявлен |
| Claude Code CLI | Файловая ссылка плюс команда открытия в браузере | [Fullscreen rendering](https://code.claude.com/docs/en/fullscreen) описывает обработку ссылок с зависимостью от терминала и режима; файловый путь может открывать менеджер файлов |
| SSH / удалённый runner | Сначала доставка HTML на компьютер читателя | Серверный абсолютный путь не является локальной ссылкой читателя. Автоматический download/port forwarding пока не реализован |

Локально обнаружены Codex CLI 0.163.0 и Claude Code 2.1.224. Это сведения об установке, а не подтверждение работы ссылок или актуальных возможностей desktop. Текущая документация может описывать более новые версии.

`delivery.py --open` отказывается запускать браузер при обнаружении SSH-сессии. В иных удалённых/container окружениях агент также должен определить местоположение файла и читателя до открытия; отсутствие SSH-переменных не доказывает локальность. Для удалённого запуска используй поддерживаемое скачивание/доставку артефактов, если оно доступно и разрешено, и выдай ссылку на фактический локальный результат. Не публикуй документ во внешнем сервисе ради кликабельности без указания пользователя.

Постоянный HTTP-демон, регистрация URL scheme и изменение глобальных настроек агентов не нужны: preview — ограниченный по времени процесс для конкретного документа. Артефакты получают уникальные имена и не удаляются автоматически. Файловый путь остаётся действительным до перемещения/удаления файла; HTTP-ссылка дополнительно требует работающего preview. На другом компьютере или телефоне `127.0.0.1` указывает на другое устройство — этот сценарий требует отдельной доставки файла.
