# Проверка визуализации

1. Входы и outputs относятся к тем же sample/run, их provenance явно подписан.
2. Recorded/replay/live/mockup различаются; missing и ограничения видны до взаимодействия.
3. Controls делают ровно обещанное, отсутствующие значения не заполняются автоматически.
4. Сторонние данные не выполняют JS/HTML, не отправляют network requests, секреты исключены.
5. Успехи и ошибки доступны по заявленному правилу отбора; графики имеют units и сопоставимые оси.
6. Текст, labels, controls читаются на широком и узком экране; клавиатура работает.
7. Browser_link проверен HTTP; визуальная проверка и проверка фактов отмечены отдельно.

Фиксируй реальные passed/failed/not_run в кратком отчёте. Скриптовая проверка ссылок/digests
не заменяет проверку смысла: красивый viewer сам по себе не доказывает качество модели/парсера.
