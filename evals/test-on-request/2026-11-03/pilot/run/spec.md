# Stable unique strings
R1: unique_in_order(items) принимает список строк и возвращает список строк без повторов.
R2: Порядок результата совпадает с порядком первого появления каждой строки во входе.
R3: Сравнение строк точное, с учётом регистра. Пустой список возвращает пустой список.
R4: Исходный список не изменяется. Вне scope: значения не-строки, не-списки, производительность.
Интерфейс: product/sequence.py, функция unique_in_order(items).
Oracle: первая позиция каждой точной строки в исходном списке.
Решение уже существует; разрешена только adversarial оценка. Исправление продукта не запрошено.
Окружение: Python stdlib, локальные файлы, без установки зависимостей и сети.
