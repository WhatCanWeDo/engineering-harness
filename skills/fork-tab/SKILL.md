# Fork Tab

Запусти установленный `~/.local/bin/fork-tab` из рабочей директории текущего проекта.
В Codex используй `--agent codex`: helper читает точный `CODEX_THREAD_ID` текущего tool call.
Это наблюдаемая возможность runtime, а не гарантированный публичный API: если ID недоступен,
нужен явно известный UUID текущей сессии через `--session`. Никогда не используй `--last`,
поиск последнего файла или выбор по mtime. Не делегируй вызов субагенту: у него другая сессия.

В Claude используй [тонкий адаптер](../../.claude/skills/fork-tab/SKILL.md), который передаёт UUID через
нативную подстановку текста skill. Не рассчитывай на одноимённую shell-переменную.

Helper создаёт только новую вкладку, не отправляя ввод в исходную. Оба чата работают
с теми же файлами; fork истории не создаёт worktree. По умолчанию новый агент использует
свои сохранённые настройки; временные CLI overrides исходной сессии не копируются.

Если процесс не связан с TTY и открыто несколько окон, `--list` покажет ID.
Попроси пользователя выбрать окно, если оно не было явно задано; не угадывай по фокусу.
macOS может запросить разрешение Automation. При отказе сообщи причину, не обходи ограничения.

`--dry-run` ничего не открывает. После `tab-created` сообщи о создании вкладки;
не выдавай это за проверенную загрузку истории — её результат виден в новой вкладке.
Не запускай команду повторно при неясном результате: сначала проверь `--list`.
Нативный `/fork` не переопределён. Установка и ограничения: [usage](references/usage.md).
