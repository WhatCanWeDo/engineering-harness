# Spec Init · авторская проверка 2026-11-06

Реализован `skills/spec-init`: фиксированный ML Task Spec v1, Scout через существующий knowledge-cycle, явные gaps с временными решениями, renderer JSON → Markdown/HTML, автономная схема с выделением связей, quiz и экспорт review. Проектные Codex/Claude entrypoints ссылаются на канонический skill.

Проверены два документа: спецификация самого spec-init с реальным developer packet из свежего Scout и иллюстративная задача BM25/embeddings с явно unavailable scouting. Учебный пример не запускал ML-эксперименты и не добавлялся в knowledge store как результат эксперимента.

Skill validator и локальные ссылки прошли. Синтаксис scripts проверен как Python 3.11; фактическое исполнение на установленном Python 3.14. Builder проверен в реальных CLI вызовах. В авторских негативных проверках отклонены: unknown без gap, dangling R-ID, непокрытое требование, user_statement без user source, неправильный граф, поле approved, другой task_id в packet. Проверены сохранение существующего output и экранирование HTML. Это техническая проверка механики, не независимый skill benchmark и не доказательство полноты постановок.

В отдельном Chrome проверены viewport 1100 и 390px, граф и его выделение, gap cards, R/AC, пять вопросов/20 вариантов, скрытая до выбора обратная связь и увеличенный шрифт 32px. Переполнения страницы/текста узлов не обнаружено. Настоящий TXT download содержит замечания, spec ID/revision и SHA-256. Наложения quiz не обнаружены на просмотренных экранах.

Предупреждение раннего draft о слишком длинных правильных ответах было исправлено содержательным редактированием вариантов. Для последующих изменений представления сохранён прежний quiz через --quiz-from, случайный порядок не подбирался.

Ограничения: live workflow в Claude не прогонялся; независимый test suite по запросу пользователя не запускался. Маршрутизация памяти, ограничения доступа и семантическая истинность источников остаются ответственностью Knowledge Core и native session. JSON validator проверяет форму/ссылки, не смысл. Review экспортируется вручную; неотправленные заметки теряются при закрытии вкладки. Согласование требует явного ответа пользователя.
