# Изображение и результат

Слева источник, справа prediction; подпиши sample/frame ID, run и recorded/live. Используй
одни и те же геометрию, класс → цвет и масштаб. Покажи source размеры и crop/resize/letterbox;
для overlay требуется фактическое обратное преобразование. При неизвестной привязке не накладывай
маску правдоподобно: покажи отдельно с пояснением missing geometry.

Полезные controls: выбор sample, overlay opacity, класс, синхронный zoom/pan, replay кадров.
Категориальные маски масштабируй nearest-neighbor. GT показывай отдельно и только если она есть;
без GT нельзя обещать accuracy/IoU. Confidence threshold нужен только при реальных score maps
и воспроизводимом postprocessing. FPS проигрывателя не равен скорости inference.

Проверь ID пары, размеры/координаты, class map и digest файлов. Нельзя заменять результат
нарисованной похожей маской. Controls должны менять лишь заявленное отображение. Новый model run,
камера или GPU требуют отдельного согласованного scope.
