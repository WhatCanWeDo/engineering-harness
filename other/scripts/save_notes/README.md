# save_notes

`save_notes` выбирает папку для скриншотов на Mac. Например, перед встречей можно выполнить `save_notes "Разбор макета"`. Скриншоты, которые вы сделаете во время встречи, будут в `~/notes/Разбор макета`. Команда сама создаёт папку.

## Установка

Откройте Терминал на Mac. Для сборки нужны Command Line Tools от Apple. Если их ещё нет, выполните `xcode-select --install` и дождитесь окончания установки.

Из корня репозитория выполните под своей учётной записью:

```sh
./other/scripts/save_notes/install.sh
```

Установщик помещает команду в `~/bin` и подключает фоновую проверку через `launchd`. При первой установке снимки будут сохраняться в `~/notes/other`. Если в настройках macOS уже выбрана папка внутри `~/notes`, установщик её сохранит. Для вызова команды по имени откройте новую вкладку zsh. В другой оболочке добавьте `$HOME/bin` в `PATH`.

## Как пользоваться

```sh
save_notes jev
save_notes "Разбор макета"
save_notes
```

Первые две команды сразу выбирают указанную папку. Последняя спрашивает её название в Терминале.

На новом Mac для снимка выделенной области нажмите **⌘⇧4** и выделите область мышью. Если привычнее **⌘⇧3**, откройте «Системные настройки» → «Клавиатура» → «Сочетания клавиш» → «Снимки экрана». Освободите ⌘⇧3 от прежнего действия и назначьте его сохранению выделенной области в файл.

## Когда снимки переходят в other

Если с последнего снимка прошло больше 24 часов, следующие снимки попадают в `~/notes/other`. Проверка срабатывает при записи файла и раз в шесть часов. Если Mac спал и первый снимок после перерыва успел сохраниться в прежнюю папку, скрипт перенесёт его в `other`. Предыдущие снимки останутся на месте.

Чтобы вернуться к работе, снова выполните `save_notes` с именем папки. Отсчёт начнётся с момента выбора.
