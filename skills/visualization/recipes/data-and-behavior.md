# Данные и поведение

Выбери представление по вопросу:

| Задача | Представление | Проверка честности |
|---|---|---|
| ETL/record flow | Одна запись по стадиям, before/after, drop/reject | Стабильный record ID, настоящие промежуточные значения |
| Search/ranking | Запрос, найденные кандидаты, rank/score и filters | Score не probability; зафиксированы query/corpus/run |
| Метрики baseline/candidate | Одинаковые оси, slices, распределения, drilldown | Сопоставимые протоколы, units, hardware и uncertainty |
| Behavior playground | Ввод → реальное детерминированное вычисление → вывод | Отличать исполнение функции от симуляции; unsupported cases явны |

Controls не должны обещать неподдерживаемые контрфактуальные результаты. Фильтрация сохранённой
таблицы — не новый поиск; изменение config — не пересчёт модели. При неизвестном результате
покажи missing и предложи отдельный run. Научные графики для экспорта делай стандартным plotting
tooling как отдельный артефакт; интерактивность не обязательна там, где она не помогает.
